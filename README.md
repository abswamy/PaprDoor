# PaprDoor
Free, legal, open source research paper access.
Because knowledge should have no walls.

## What it does
- Search 200M+ papers by DOI, title, or keywords
- Find free legal PDF versions via Unpaywall
- Excavate references and track citations
- Author Connect — email authors directly
- India First — Shodhganga integration coming

## How to use
Open index.html in a browser.
No installation needed.

## Tech stack
Vanilla HTML/CSS/JS — no framework
CrossRef + OpenAlex + Unpaywall + Semantic Scholar
